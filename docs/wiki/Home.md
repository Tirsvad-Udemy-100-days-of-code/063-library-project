# Library Project (Day 63)

This project follows Day 63 of the Udemy course *100 Days of Code: The Complete Python Pro Bootcamp*. The goal is a virtual bookshelf: keep the books you have read and give each a rating.

The lecture has four steps. Each step has its own page with screenshots and a short text about what we learned.

- [Step 1](Step-1-In-Memory-Library): a Flask website that keeps books in a Python list.
- [Step 2](Step-2-Sqlite3-Lesson): the first database, with the `sqlite3` module.
- [Step 3](Step-3-SQLAlchemy-Lesson): the same database written as Python classes with SQLAlchemy.
- [Step 4](Step-4-Library-With-Database): the website with the database: add, list, edit rating and delete.
- [Project structure](Project-Structure): how the code, the tests and the screenshots are organised.

To run the code you need Python 3.13 or newer. The README explains how to create a `.venv`, install the project and run the tests.
