# Projek Perpustakaan (Hari 63)

Projek ini mengikuti Hari 63 kursus Udemy *100 Days of Code: The Complete Python Pro Bootcamp*. Matlamatnya ialah rak buku maya: simpan buku yang telah anda baca dan beri setiap buku satu penilaian.

Pelajaran ini mempunyai empat langkah. Setiap langkah mempunyai halamannya sendiri dengan tangkapan skrin dan teks ringkas tentang apa yang kita pelajari.

- [Langkah 1](Step-1-In-Memory-Library-ms): laman web Flask yang menyimpan buku dalam senarai Python.
- [Langkah 2](Step-2-Sqlite3-Lesson-ms): pangkalan data pertama dengan modul `sqlite3`.
- [Langkah 3](Step-3-SQLAlchemy-Lesson-ms): pangkalan data yang sama ditulis sebagai kelas Python dengan SQLAlchemy.
- [Langkah 4](Step-4-Library-With-Database-ms): laman web dengan pangkalan data: tambah, senarai, ubah penilaian dan padam.
- [Struktur projek](Project-Structure-ms): bagaimana kod, ujian dan tangkapan skrin disusun.

Untuk menjalankan kod, anda perlukan Python 3.13 atau lebih baharu. README menerangkan cara mencipta `.venv`, memasang projek dan menjalankan ujian.
